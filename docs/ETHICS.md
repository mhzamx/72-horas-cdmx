# Límites éticos y de interpretación

1. **No reidentificación.**  
   El proyecto no intenta inferir nombres, domicilios, teléfonos ni identidades.

2. **No predicción individual.**  
   No se asignan “riesgos” a personas concretas.

3. **No culpabilización.**  
   Un tiempo alto no demuestra negligencia por sí mismo. Puede reflejar diferencias de caso, calidad del registro, actualización tardía u otros factores no observados.

4. **No confundir fecha de registro con inicio material de búsqueda.**  
   El dataset público puede no capturar con precisión todas las acciones institucionales ejecutadas antes o después del registro.

5. **Casos localizados.**  
   La fecha de localización puede ser actualizada después del evento real. Esto debe verificarse en la documentación de la fuente.

6. **Datos incompletos.**  
   El registro interno de la CBPCDMX no equivale a todos los casos del RNPDNO asignados a Ciudad de México.

7. **Publicación.**  
   En GitHub deben publicarse código y datos agregados. El archivo a nivel registro debe mantenerse fuera del repositorio salvo que se confirme expresamente que la licencia y las condiciones de la fuente permiten redistribuirlo.
